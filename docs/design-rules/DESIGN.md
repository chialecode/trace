# TRACE 交互与界面约束

适用于 UI、状态文案、组件和可视化改动。2026-10-07 用户指定白色参考图，采用下述蓝白视觉基线（DEC-015）；主观体验反馈见 [ACT-004](../../USER-ACTIONS.md#act-004)，不再把风格作为未决定前置。信息架构以[需求](../requirements.md#information-architecture)为准。

## 基本任务

首个版本应能从创作者进入账号与视频时间线，看到保存结果、失败原因和重试入口，查看视频与来源，进行字面搜索，并找到后台状态、导出和恢复。不要为了完整导航显示大量不能工作的未来入口。

来源账号与登录账号使用不同概念。任务完成、内容已保存、质量达标和历史覆盖分别表达；未知、部分成功、待登录、限流、磁盘不足、恢复中均有真实状态与可执行下一步。

关闭界面与完全退出为不同操作；首次关闭时解释后台行为。停止订阅不删档案；删缓存、删副本、删档案的影响范围清楚呈现，引用保护仍由核心执行。普通查看、暂停、重试不额外叠加确认。

## 组件与可用性

- 前端固定 Vue，首轮用 Naive UI；版本与比较在[技术选择](../research/2026-09-26-technology-stack.md)。复用成熟焦点、弹窗、菜单、表单和键盘语义，避免手写平行基础组件；仍须真实测试键盘/IME，不能用选库代替可用性证据。
- 在前端栈确定后建立语义 Token 和共享组件；颜色、间距和字体策略集中维护。支持哪些主题在视觉方案中说明并按实际范围验证，不能从参考工程继承双主题已完成的承诺。
- 关键路径可用键盘操作，焦点可见且弹窗关闭后合理恢复；中文输入法、长中文标题、窄窗和 Windows 缩放不能阻断操作。
- 状态不只依赖颜色；图片有语义替代，加载/空态/错误/部分成功均需覆盖。分页和按需加载避免一次渲染整个档案。
- 原件无法播放时说明原因并提供受控外部打开或派生预览；不得将转码预览冒充原始质量。
- 归档正文不执行来源脚本，不自动加载来源跟踪资源，不把不可信链接变成任意文件或命令入口。

## 交付证据

UI 变更附对应版本、页面状态、操作路径与实际观测；截图只能证明所见状态，不能证明后台、恢复、键盘或输入法正确。自动验证与必要人工步骤分别记录；视觉偏好集中到可运行原型后确认。

自动窗口检查使用隔离 Profile、独立 WebView 和不激活窗口，不影响用户前台或读取其浏览器会话；具体边界见[质量门禁](../dev-rules/quality-gates.md)。新增登录/未登录时间线及统一资源升级页按[获取认证契约](../site-archive-contracts.md#authentication-acquisition)实现：标签表达获取当时事实，未知/混合状态明确；切换筛选或处理候选不重建仍有效的媒体节点，覆盖决定在可比较的候选就绪后由用户作出。

可公开摘要放 `docs/evidence/` 并登记；含参考作品画面的截图按[本地规则](../dev-rules/local-reference-and-files.md)留在仓库外。最终文案遵守[需求用语](../requirements.md#scope)，技术实现名只有帮助用户做决定时才显示。

## 蓝白三栏视觉基线

语义 Token 正本是 `apps/desktop/src/styles/shell.css`；页面排列在 `home.css`。近白背景，主色 `#3979ff`，深蓝正文，分割线 `#e6eefb`，8～9px 圆角、系统中文字体。默认浅色，不声称完整暗色主题已验收。

1536×1024 基准：左栏约 254px、顶栏 59px、详情 382px，中栏自适应；头像/横幅、类型筛选、统计、日期时间线、来源/保存/操作详情。980px 以下详情移至下方，760px 以下导航收为图标。原生 IME/缩放按 ACT-003 检查。

浏览器为明确标记的示例，桌面默认真实档案。示例数量、统计、日期、订阅和文件大小只供视觉对照；示例动作不调用写入 API。真实档案不使用这些数值，缺图占位、失败/空态准确，当前页统计标范围。原生窗口控制由 Tauri/系统提供，不画无效网页关闭按钮。

主页保留该视觉基线；创作者选择、全局统计、真实封面/订阅、受控媒体与新增内容类型按[当前计划](../delivery/stage-plan.md) P7/C08核对。当前实现及事件保留证据见[阶段报告](../delivery/stage-report.md)，原生体验仍由ACT-003独立验收。生产构建不复制参考原图，分发素材另核资产许可。
