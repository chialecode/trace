# 移动端选型（2026-11-26）

为 [DEC-085](../decisions.md#dec-085) 的移动端做的选型记录，只对查询当时的版本有效。设计见[移动端设计](../design/mobile.md)。

- 本机 `go tool mygo doctor`（v0.10.0）与隔离原型 [#117](https://github.com/chialecode/trace/issues/117) 在 Android 16（API 36）模拟器及 Windows 11 上的实测结果，2026-11-26（脱敏回执 `artifacts/mobile-proto/proto-report.json`）。
- 开源二维码解码候选查证（2026-11-26）：AndroidX CameraX（Maven Central `androidx.camera:camera-core:1.6.2`）、ZXing Core（Maven Central `com.google.zxing:core:3.5.4`，2025-11-11 发布）、`github.com/makiuchi-d/gozxing`（`v0.1.1`）、`github.com/tuotoo/qrcode`、`github.com/liyue201/goqr` 及 Google Play Services Code Scanner 文档。

## 2. MyGo 的手机支持（v0.10.0）

| 方面 | 现状 |
| --- | --- |
| 平台 | iOS / iPadOS（原生界面用 Metal 绘制）与 Android（OpenGL ES）；Go 代码、绑定的服务与事件不变 |
| 命令 | `mygo doctor`、`mygo devices`、`mygo dev -platform android|ios`（改 Go 代码约 2 秒重启并恢复路由与 `ui.Local` 状态）、`mygo build -platform android`（`.apk` 与 `.aab`）/ `ios`（签名 `.ipa`）、`mygo publish` |
| 构建条件 | Android：SDK（`compileSdk`/`targetSdk` 36，默认 `minSdk` 26）、NDK（用其 clang 为每个 ABI 链接 Go 共享库）、JDK 17 或以上，Gradle 构建，任何桌面系统都可以；iOS：只能在装 Xcode 的 Mac 上构建，真机与上架要 Apple 开发者团队 |
| 开发版 | 名称加“ Dev”、标识符加 `.dev`，与正式版并存 |
| 界面 | `mygo.NewTabs`（系统底部标签栏）、`Window.Push` 与 `ui.Router.SystemStack`（系统导航栈、Android 预测性返回、iOS 左滑返回）；`ui/mobile`：`Sheet`、`ActionSheet`、`Drawer`、`PageView`、`SwipeRow`、`TopBar`/`BottomBar`、`ListRow`/`Section`、`Switch`、`Zoomable` 等；`Element.PullToRefresh`；手指、长按、双指缩放；输入法与系统编辑菜单；TalkBack / VoiceOver |
| 生命周期 | 应用不自己退出；后台是 `Power.OnSuspend`，回前台是 `resume` 与 `App.OnActivate`；系统可能在后台结束应用，`App.OnSaveState` / `RestoredState` 恢复；内存不足 `App.OnMemoryWarning` |
| 设备能力 | `mygo.Network`（是否在线、是否计费）、`mygo.Share`、`mygo.Haptics`、`mygo.SetOrientations`、`Context.SafeArea`；`Secrets` 在 Android 上用密钥库加密保存 |
| 官方插件 | `videoplayer`（Android MediaPlayer / iOS AVPlayer，文件或 URL，含 HLS）、`camera`、`imagepicker`、`permissionflow`、`preferences`、`background`、`push`、`websocket` 等；自写原生代码用原生模块（Kotlin / Swift） |
| 手机上不起作用 | 菜单栏、托盘、程序坞、全局快捷键、更新器（由应用商店更新） |
| 测试 | `ui.Tester` 的 `FingerDown/Move/Up` 与 `SetInsets`、`ui/golden` 截图比对；自动化插件可在模拟器与真机上做端到端测试 |

本机 2026-11-26：仓库已升级到 MyGo `v0.10.0`（[#115](https://github.com/chialecode/trace/issues/115)）；Android 构建链已安装并由 `go tool mygo doctor` 确认可用（[#116](https://github.com/chialecode/trace/issues/116) 已关闭）：Android SDK（`platforms/android-36`、`android-37.0`、`build-tools/36.0.0`）、NDK `30.0.16248370`、adb `1.0.41`、Android Studio JBR `25.0.4` 与 AVD `Trace`（Android 16 / API 36）。实测同时发现 MyGo `v0.10.0` 在 Windows 上存在两项上游缺陷：① `internal/mobile/android/embed.go` 遗漏 `gradlew.bat`；② 固定的 Gradle `8.14.3`（内置 Kotlin DSL `2.0.21`）+ `jvmToolchain(17)` 与 JBR `25.0.4` 不兼容，实际构建须通过 `JAVA_HOME` 指定 **JDK 17**（原型用 Eclipse Temurin `17.0.21.1+2` 验证通过）并在 `.mygo/android/` 补放 `gradlew.bat`。

## 3. 方案比较

| 方案 | 结论 | 理由 |
| --- | --- | --- |
| **MyGo 原生应用（选用）** | 采用 | 全项目已是 Go + MyGo 原生界面（DEC-032），手机端可共用 DTO、协议类型与部分展示代码；同一工具链出 Android 与以后的 iOS；与持续同步 MyGo 最新版的方向一致 |
| 电脑端提供网页，手机用浏览器打开 | 不采用 | 局域网自签名证书在浏览器里会出现安全警告，要用户手动信任；要另写一套网页前端（项目已去掉 Web 前端，DEC-032）；后台与返回手势等体验差 |
| Kotlin / Flutter 等原生框架 | 不采用 | 引入第二套语言与工具链，不能与电脑端共用代码，违背 DEC-032 的单一语言取舍 |

## 4. 原型核对与开源选型结论（[#117](https://github.com/chialecode/trace/issues/117)）

### 4.1 二维码扫描开源选型（2026-11-26 查证）

按[开源优先](../dev-rules/sources-and-safety.md#open-source)核对各候选：

| 候选 | 来源与版本 | 维护 | 适用范围 | 许可 | 集成成本 | 实证与结论 |
| --- | --- | --- | --- | --- | --- | --- |
| **AndroidX CameraX `1.6.2` + `com.google.zxing:core:3.5.4`（选用，经 Kotlin 原生模块）** | Maven Central：`androidx.camera:camera-{camera2,lifecycle,view}:1.6.2`；`com.google.zxing:core:3.5.4`（2025-11-11 发布） | CameraX 由 Google Jetpack 持续活跃维护；`zxing:core` 处于低频维护但 2025-11 仍有 3.5.4 安全/维护发行 | Android API 26+，完全离线、零 GMS 依赖（兼容国内无 GMS 手机与自定义 ROM），实时帧分析无落盘 I/O | 均为 **Apache-2.0**（CameraX 内部 `libyuv` 为 BSD-3-Clause）；需保留 NOTICE/许可声明 | 中低：与 MyGo `plugins/camera` 共用同版本 CameraX；以 `native.View` 嵌入 `ui.NativeView`；实测 R8 压缩后单 ABI APK 仅增 `+0.38 MiB` | **采用**。已在 Android 16 模拟器实测构建并识别 TRACE `yeqown/go-qrcode/v2` 生成的常规与反相 `trace-pair:` 二维码（需在 Kotlin 侧加 `LuminanceSource.invert()` 回退） |

### 4.2 视频播放、解码能力、防火墙与构建链实证

- **视频播放与回环明文**：已验证 `plugins/videoplayer`（Android `MediaPlayer`）经手机端 `127.0.0.1:<随机端口>` 回环转发 + 固定指纹 TLS 1.3 连电脑可行，10.22 MiB（150 秒）合成 MP4 `Seek` 实测触发 `Range: bytes=7778518-` → `206 Partial Content`。但 Android 16 默认阻断 `127.0.0.1` 明文（未配时代理 0 命中），而 MyGo `mygo.json` / `mygo-plugin.json` 不能改 `<application>` 属性，必须经同一 Kotlin 原生模块合并 `android:networkSecurityConfig="@xml/trace_network_security_config"`（仅允许 `127.0.0.1` 与 `localhost` 明文）。
- **解码能力与失败判定**：合成 AVC、HEVC、AV1（320×240）与 RFC 9639 FLAC-in-MP4（`fLaC`/`dfLa`）均在 Android 16 模拟器经回环代理播通并可拖动；但实测发现“视频轨不可解 + 音轨有效”时 `MediaPlayer` 会静默丢弃画面（`ready=true, playing=true, err="", width=0, height=0`），且音频软件解码器或软解 AV1 有分辨率上限（如模拟器 `c2.android.av1-dav1d.decoder` 上限 2048×2048）。定案为 `MediaCodecList` 预检 + 播放期错误/零宽高双层判定。
- **Windows 防火墙**：非提权按用户进程监听局域网 IPv4 在系统归类为 `Public` 且未 UAC 批准时，Windows 会自动写入持久 `Inbound Block` 规则且不再弹窗，须在电脑端“设置 › 移动端”说明并在实现后做真机检查。
- **构建耗时与产物**：冷构建三 ABI `4m 16s`（APK `39.5 MB` / AAB `16.9 MB`），热构建 `android/arm64` `4.8s`（APK `14.2 MB`，加原生模块与 CameraX+ZXing 后 `14.6 MB`），`mygo dev` 冷装 `37.5s`、纯 Go 热重载 `2.6s`。详见[移动端设计 §9](../design/mobile.md#risks)。
- **局域网自动发现**（第二版）：mDNS 的 Go 实现与 Android 组播权限留待第二版选型时查证。
