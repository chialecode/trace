# 技术选型研究：Go + MyGo 原生界面（Native UI）

查询日期：2026-11-05，2026-11-07 更新；B 接入与许可核对：2026-11-08（UTC+8）。决定见[有效决定](../decisions.md) DEC-016、DEC-032。

## 1. 为什么是全 Go + MyGo 原生界面

TRACE 需要经常修改后端的站点逻辑，同时希望在不同 Windows 电脑上都有一致的运行体验，不受系统 WebView2 运行时差异、子进程内存占用或跨源协议行为影响（DEC-016、DEC-032）。

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| **Go + MyGo 原生界面 `mygo/ui`（选定，DEC-032）** | 纯 Go 单一工具链（`CGO_ENABLED=0`），增量编译以秒计；Direct3D 11 硬件加速（无可用显卡驱动时自动回退 WARP 软件渲染）；不启动 `msedgewebview2.exe` 子进程；`ui.NewTester` 可在 `go test` 内存里直接跑完整界面测试与导出 PNG 截图；同一套 `ui.View` 未来还能编译为 WebAssembly 在浏览器运行 | 原生 `ui.Video` 只内建 GIF 解码，MP4 音视频播放需要接系统解码器（Windows Media Foundation + `mygo/audio`，见[媒体选型 §3](2026-11-05-media.md#playback)） |
| Go + MyGo WebView2 + React（原 DEC-016/017，已替代） | 网页组件生态成熟 | 依赖客户机 WebView2 环境；后台与多进程内存高；自定义协议开放区间等边缘行为受 WebView2 影响 |
| Rust + Tauri | 包体小 | Rust 编译慢，且同样依赖系统 WebView |
| Electron | 生态最大 | 自带 Chromium，包体与内存占用大；后端是 Node |

## 2. 桌面外壳与原生界面：MyGo v0.8.1

[MyGo](https://github.com/egoist/mygo) 提供桌面应用生命周期（窗口、托盘、单实例、通知、对话框、NSIS 安装器）以及声明式原生界面包 `github.com/egoist/mygo/ui` 与音频包 `github.com/egoist/mygo/audio`。按 DEC-032，项目持续同步 MyGo 最新版本（当前 `v0.8.1`），不保留旧版兼容包袱。

| 维度 | 证据（查验 `proxy.golang.org` 与 `github.com/egoist/mygo@v0.8.1` 源码及 `docs/`，2026-11-07） |
| --- | --- |
| 版本与活跃度 | `v0.8.1` 发布于 2026-11-06（`v0.8.0` 同日发布）；首个版本 `v0.1.0` 发布于 2026-09-27，持续高频迭代 |
| 许可 | MIT（仓库 `LICENSE`） |
| 要求 | `go.mod` 要求 `go 1.27.3`；全程 `CGO_ENABLED=0`（Windows 上通过系统 DLL 与 Direct3D 11 / DirectWrite / WASAPI 通信） |
| 直接依赖 | `purego`、`go-text/typesetting`、`go-mp3`、`oggvorbis`、`golang.org/x/{image,net,sys,text}`；打包时将实际链接模块的许可写入 `THIRD-PARTY-NOTICES.txt` |
| 原生窗口与渲染 | `mygo.NewWindow(mygo.WindowOptions{Title, Width, Height, Content: ui.View(view)})` 创建不带 WebView2 的原生窗口（`Hide()` / `ShowInactive()` 控制是否显示与激活）；Windows 用 Direct3D 11 渲染，驱动不可用时自动退回 WARP，也可设 `MYGO_GPU=0` 强制 CPU 渲染（`docs/ui/rendering.md`） |
| 文字与输入法 | Windows 用 DirectWrite 排版与系统字体回退（含中日韩与 Emoji，`docs/ui/text.md`）；`ui.TextInput` / `ui.SearchField` 原生处理 Windows IME 组合输入（组合态按回车只上屏候选词，不触发提交） |
| 虚拟列表与滚动 | `ui.List(c, &listState, items, ...)` 只构建可见行并支持不等高行（`docs/ui/list.md`）；`ui.ScrollView` 支持讀取与设置 `ScrollState.Offset`、判断 `AtBottom()`（`docs/ui/scroll.md`） |
| 异步与线程安全 | 后台 goroutine 用 `Window.Update(func() { ... })` 在主线程改状态并重绘，只需重绘时用 `Window.Invalidate()`；`mygo.RunOnMain` 只切线程不重绘（`docs/ui/views.md`） |
| 界面测试与截图 | `ui.NewTester(view, w, h)` 在 `go test` 内存里运行视图树，支持 `Click`、`Type`、`Compose`（输入法组合态）、`Scroll`、`SetSize`、`Find`（读取节点坐标盒断言三栏布局与无溢出）、`AccessByRole`（无障碍角色与名称）以及 `Image()`（直接输出 `*image.RGBA` 生成 PNG，无需浏览器或桌面会话，`docs/ui/testing.md`）；`github.com/egoist/mygo/plugins/automation` 还可在真实进程内驱动窗口与截图 |
| 外壳能力 | 系统对话框（`DialogModule.Open`）、`Shell.OpenExternal`、`Shell.ShowItemInFolder`、单实例锁（`RequestSingleInstanceLock` / `OnSecondInstance`）、托盘与菜单（`mygo.NewTray`）、系统通知（`mygo.Notification`）、NSIS 按用户安装包（`mygo build`） |
| Web / 跨端扩展 | `docs/ui/browsers.md`：`mygo build -platform web` 可把同一套 `mygo/ui` 视图编译为 `GOOS=js GOARCH=wasm` 在浏览器 Canvas/WebGL2 中运行 |

来源：[GitHub 仓库](https://github.com/egoist/mygo)、[pkg.go.dev 版本列表](https://pkg.go.dev/github.com/egoist/mygo?tab=versions)，以及 Go 模块缓存 `github.com/egoist/mygo@v0.8.1` 源码（`native_window.go`、`ui/`、`audio/`、`plugins/automation/`、`docs/native.md`、`docs/ui/*.md`、`docs/audio.md`）。

## 3. 各部分选型结论

| 部分 | 结论 | 理由 |
| --- | --- | --- |
| Go 版本 | `1.27.3`（`go.mod` 的 `go 1.27.3`） | MyGo `v0.8.1` 要求；本机已装 `go1.27.3 windows/amd64` |
| 界面技术 | `github.com/egoist/mygo/ui` 原生界面（DEC-032） | 彻底去掉 WebView2 与 Node/npm/React/Vite 工具链；不同电脑体验一致，内存占用低，测试与截图可在 `go test` 内直接完成 |
| 服务层边界 | `internal/ui` 通过 Go 接口调用 `internal/service`，`internal/service` 及下层包不依赖 `mygo`（INV-05） | 保证桌面 UI 与业务核心解耦；未来提取远程服务器（VPS）轻量录制模式时，可直接给 `internal/service` 加一层标准库 `net/http` JSON 接口与轻量 Web 页面（或把 `internal/ui` 编译为 WASM）进行远程配置（[架构设计 §9](../design/architecture.md#headless-ext)） |
| 任务运行器 | 质量门禁、截图与打包全部写成纯 Go 程序（`go run ./tools/check`、`go run ./tools/uishots`、`go run ./tools/smoke`、`go run ./tools/package`） | 一条命令、零外部脚本运行时依赖 |
| 安装器与数据位置 | MyGo 自带 NSIS 按用户安装器（正式版 `%LOCALAPPDATA%\Programs\trace`、开发版 `trace-dev`），数据在 `%LOCALAPPDATA%\trace[-dev]`、缓存在“文档\trace[-dev]”（DEC-029） | 不需要管理员权限；不再需要 `webview2/` 目录 |
| 凭证保存 | 保持 DPAPI 加密文件（`<数据目录>/credentials/bilibili.bin`），不用 `mygo.Secrets` | `mygo.Secrets` 受 Windows 凭据管理器 2560 字节上限限制且存在数据目录外；DPAPI 文件随数据目录隔离（[架构设计 §5](../design/architecture.md#credentials)） |
| 本地媒体读取与播放 | 路径白名单（`Library.MediaPath`）+ 原生图片/视频播放组件（Windows Media Foundation + `mygo/audio`，见[媒体选型 §3](2026-11-05-media.md#playback)） | 原生界面直接读受控的本机文件，不再需要 WebView 自定义协议 `trace-media://` |
| 二维码生成 | `github.com/yeqown/go-qrcode/v2` v2.3.0（备选 `rsc.io/qr` v0.2.0） | 纯 Go 把扫码登录 URL 编码为矩阵并渲染成 `*image.RGBA` 交给 `ui.Image` 显示，不落盘、不发外站请求 |
| 索引数据库、音视频合并 | `modernc.org/sqlite` v1.61.1、`github.com/Eyevinn/mp4ff` v0.62.0 | 纯 Go，无需 cgo（[媒体与存储选型](2026-11-05-media.md)） |

## 4. 界面与二维码依赖

无需任何 npm / JavaScript 依赖。Go 侧界面与二维码依赖查询结果（2026-11-07，`goproxy.cn` / `proxy.golang.org`）：

| 模块 | 版本与日期 | 许可 | 用途与取舍 |
| --- | --- | --- | --- |
| `github.com/egoist/mygo` | `v0.8.1`（2026-11-06） | MIT | 原生窗口（`NewWindow` + `ui.View`）、声明式界面（`mygo/ui`）、音频播放（`mygo/audio`）、托盘、单实例、对话框、内存测试器（`ui.NewTester`）与自动化插件（`plugins/automation`） |
| `github.com/yeqown/go-qrcode/v2` | `v2.3.0`（2026-08-05） | MIT | 活跃维护；纯 Go 生成二维码位图矩阵，在内存里转为 `*image.RGBA` 供登录页显示。备选：`rsc.io/qr` `v0.2.0`（BSD-3-Clause，零外部依赖，直接返回 `Code.Image()`） |

B 已按选定版本接入二维码矩阵 API，无需图片写出器。传递模块 `github.com/yeqown/reedsolomon v1.0.0` 的归档没有 LICENSE；2026-11-08 核对[官方许可](https://github.com/yeqown/reedsolomon/blob/c5f4bc9af094852b52e593a5f964647c43028c51/LICENSE)及[版本比较](https://github.com/yeqown/reedsolomon/compare/v1.0.0...c5f4bc9af094852b52e593a5f964647c43028c51)，下一提交仅增加 MIT LICENSE、源码未变。原文作为精确版本的[许可补充](../../tools/package/licenses/README.md)入库并随包收录；不修改模块缓存。

界面字体（DEC-039，2026-11-08 查证官方发布页 <https://github.com/rsms/inter/releases/tag/v4.1>）：

| 维度 | 证据 |
| --- | --- |
| 来源与版本 | Inter 4.1，官方发布 `Inter-4.1.zip`（2024-11-16，查证时的最新发布），取其中的 `InterVariable.ttf`（可变字体，SHA-256 见 `internal/ui/fonts/README.md`），未修改 |
| 维护 | 仓库未归档；两次发行间隔较长（4.0 到 4.1 约一年），近期提交活跃度本次没有逐条核对，记为 unknown |
| 许可 | SIL Open Font License 1.1；可随软件打包，原文 `OFL.txt` 随包写进 `THIRD-PARTY-NOTICES.txt`（`tools/package` 缺文件时失败） |
| 适用范围 | 只含拉丁、希腊、西里尔字母；中文由 DirectWrite 回退到系统字体（Windows 为微软雅黑）。本机 `ui.NewTester` 实测 400/500/600/700 字重与中文回退正常 |
| 集成成本 | 程序增大约 0.9 MB；`ui.RegisterFont` 失败时界面退回系统字体，不影响启动。备选：系统 Segoe UI（不打包，但与参考设计的观感差别大） |

公开图片额外注册既有 `golang.org/x/image v0.46.0` 的 WebP 解码器，该模块由传递依赖改为直接依赖，BSD-3-Clause 原文及 PATENTS 随包收录；本次没有重新查询其上游发行活跃度。
