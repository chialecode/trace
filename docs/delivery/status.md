已知限制：没有可用 GPU 的电脑走软件解码，界面不会卡死，但高分辨率 60 fps 视频可能掉帧；本机没有 cgo 工具链，`go test -race` 无法运行（记为 `not-run`）；直播录制 MVP 只支持 HLS fMP4 流（仅提供 FLV/TS 的直播间见 LOOP-004）。
