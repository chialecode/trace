# TRACE 路线与验收

本页回答“先做什么、做到什么程度算基本可用、怎样判定完成”。需求的正本是[需求](../requirements.md)，实际做到哪以[需求](../requirements.md)的状态列与 `main` 上的代码为准，真实站点与人工检查的进展在 [`needs-user` issue](https://github.com/chialecode/trace/issues?q=is%3Aissue+label%3Aneeds-user) 里跟踪；不能从本页的范围或预期判断功能已经通过。

<a id="principles"></a>
## 1. 交付原则

- **先贯通全部基本功能的 MVP，再按反馈 loop 迭代**（DEC-004；用户 2026-11-07 重申）。每项基本能力先做出第 3 节“MVP 必须”的完整流程，再处理“可由 loop 深化”的部分；不等一个功能的全部打磨项清零才推进下一个基本功能。
- **MVP 不放宽底线**：数据正确、凭证隔离、真实状态（风控、限流、未登录、网络、不可得、格式变化、存储失败分别说明）、只删登记过的文件、规则请求的频率上限，都不因 MVP 放宽。
- **以完整可用的流程为交付单位**：每个 issue 做成一个小 PR（[开发流程 §2](../dev-rules/workflow.md#change-loop)），一个阶段要贯通的流程按第 3 节列出；不以内部测试轮次或单个示例为交付单位。
- 不影响基本使用、没有数据或真实状态风险的问题建成 [`feature` issue](https://github.com/chialecode/trace/issues?q=is%3Aissue+label%3Afeature)；产品取舍建 [`needs-user` issue](https://github.com/chialecode/trace/issues?q=is%3Aissue+label%3Aneeds-user)。MVP 达成、阶段合并、产品验收（人工检查）与对外发布是不同的事实。

<a id="mvp-loop"></a>
## 3. MVP 基线与反馈循环

“全部基本功能”按需求主线解释如下。下表每一行的“MVP 必须”都存在且可验证，才称 MVP 完整；单个功能的演示不等于 MVP 完成。

| 基本能力 | MVP 必须能完成的流程 | 可由后续 loop 深化 |
| --- | --- | --- |
| 登录与凭证 | 扫码与粘贴 Cookie 登录；未登录不发请求；失效时暂停任务、回到登录页、重新登录后回到原处；扫码登录在应用运行时自动续期，失败不丢旧凭证 | 多个登录账号；续期提醒的界面细节（粘贴 Cookie 的登录不续期，DEC-031） |
| 解析与浏览 | 视频、用户、动态、投稿、直播间链接都能打开；滚动加载、风控停在原处可重试；看原图 | 专栏全文、合集与系列、搜索；更多链接类型 |
| 缓存与下载 | 手动缓存动态与视频，最高画质与音质、多 P；用户页与定期“全部缓存”后台慢速不规律队列及已缓存条目无损升级复查（DEC-050 ①、[DEC-076](../decisions.md#dec-076)）；断连续传；升级探测与升级；弹幕与字幕随视频保存；任务页侧栏（含“内容冲突”归档优先处理）与详情逐文件进度 | 弹幕 ASS 导出、弹幕更新、按条件筛选缓存内容、下载限速 |
| 主页、媒体库与播放 | 信息流（从新到旧、有更新的头像行与单订阅视图、无底部文字按钮）、媒体库（固定发布时间从新到旧排序、按类型与订阅/作者筛选、纯离线 `/library/item` 本机详情与播放、每格简洁展示与“⋯”菜单、删除只删登记文件与变空的作者文件夹，DEC-037、DEC-049 ③、DEC-051 ②）、播放层可开关弹幕、调透明度与密度、选择字幕 | 弹幕屏蔽词、播放列表、画中画、更多播放器快捷键 |
| 订阅 | 新建、改名、删除订阅；关联与解除账号（一个账号只属于一个订阅）；用户页加入订阅；从关注列表导入；订阅页圆形头像网格（本机头像副本）与订阅详情的“内容”“账号”两个标签、缓存能力标签开关及按标签/跨订阅批量管理（DEC-051 ⑥⑦⑧、DEC-070） | 订阅分组、排序与搜索、批量编辑备注、订阅导出导入 |
| 检查更新与规则 | 手动检查（第一次检查只建立起点、起点之前的动态不进入更新、风控停止整轮；不做已看标记，DEC-033）；定时检查（退避、每小时额度、每轮上限）；按订阅规则自动缓存（只缓存规则开启后发布的，每轮上限） | 每个订阅单独的检查间隔、关键词与时长等规则条件、通知提醒 |
| 直播 | 开播状态显示；手动开始与停止录制（fMP4 流与 HTTP-FLV 后备，不限制同时录制数）；“任务 › 直播录制”页内 `.part` 实时预览（DEC-049 ①，无额外站点连接）与“录制异常”按场记录（DEC-051 ③）；开播自动录制；断流重连与换段；录像条目可播放、删除 | HLS-TS 后备（LOOP-008）、直播弹幕录制与实时弹幕（FR-LIVE-003）、录像合并 |
| 后台运行 | 关闭窗口到托盘并释放界面内存，后台继续缓存、定时检查、自动缓存、录制与续期；托盘重新打开、退出确认；单实例 | 开机自动启动、托盘里的更多快捷操作 |
| 安装、数据与打包 | 按用户安装到 `%LOCALAPPDATA%\Programs\trace`（开发版 `trace-dev`），数据在 `%LOCALAPPDATA%\trace`、缓存在“文档\trace”，两个通道隔离；接入旧的缓存文件夹；一条命令打包开发版安装包、只留最新产物；门禁一条命令；开发版打包后本机自动更新，正式版一条命令发布并联网更新（设置“更新”页统一显示版本、通道更新方式与检查/更新记录，DEC-051 ①） | Windows 代码签名、winget 与 Microsoft Store、测试版通道、差分包体积优化 |
| 抖音（DEC-043） | 粘贴 Cookie 登录、按站点登录互不影响；分享文本与各类链接解析；作品详情（视频、图文、实况、配乐）与用户作品列表；缓存视频（最高档、无水印、单文件 MP4）与图文；订阅关联抖音账号、检查更新（置顶不打断）、自动缓存；开播状态与 FLV 录制（原画优先、断流重连、换段、收尾）；站点小字标记与按站点筛选；抖音与哔哩哔哩的额度、退避与熔断互不影响 | 扫码登录、关注导入、合集与喜欢收藏、直播弹幕、HLS-TS 后备（LOOP-008）、画质升级提醒、评论 |
| 我的（DEC-047） | “我的”页按站点折叠的功能；哔哩哔哩关注（含分组）、收藏夹、稍后再看、历史记录，抖音关注、喜欢、收藏（全部与收藏夹）、观看历史都能翻页浏览，风控、未登录、失效、网络、空与到底分别说明；视频、作品、用户点开详情并能缓存，用户能加入订阅；返回时列表与位置保留；列表不落盘 | 一键缓存整个收藏夹或稍后再看、收藏的合集与追番、写操作（取消收藏、删历史） |
| 远程版（DEC-062） | `trace-server` 在 Linux 上 `init` 与 `run`；本地用连接码连接、看状态、同步订阅与 Cookie；远程只按规则缓存起点之后的新内容与录制，内置 rclone 上传并删除已上传的文件；媒体库从文件夹增量导入（预览、冲突选择、未传完的部分导入后再补）与导出；订阅导出导入 | 集群模式与多个远程、远程网页、本地自动从网盘拉取、导入时转码或去重相似内容 |
| 微博（DEC-065） | 粘贴 Cookie 登录（严格确认已登录、不续期），三个站点登录互不影响；分享文本、`t.cn` 短链与各类微博、视频、用户链接解析，不支持的链接给提示且不发请求；单条微博详情（长微博全文、转发与原微博不可见的说明、超过 9 张图、GIF、实况、混排、视频、文章与直播等卡片的摘要）与用户微博列表（置顶、翻页、可见范围提示、空壳与真空区分）；缓存视频（最高档单文件 MP4）与正文图片（原图、默认无损 `/oslarge/` 去水印开关并自动回退原地址、GIF 保持原样、实况片段、混排），转发存转发者文件夹；订阅关联微博账号、检查更新（置顶与快转不打断）、自动缓存、全部缓存原创；从微博关注列表导入；我的 › 微博的关注与收藏；站点小字“微博”与按站点筛选；微博的额度、退避与熔断独立；远程版推送微博 Cookie 与同步微博订阅 | 扫码登录、直播状态与录制、赞过与关注分组（ACT-022 确认后）、原创筛选、评论、头条文章正文、视频合集、画质升级提醒 |
| X（DEC-066） | 粘贴 Cookie 登录（登录页如实说明账号风险、严格确认已登录、不续期），四个站点登录互不影响；分享文本、`t.co` 短链、镜像与各类帖子、用户链接解析，不支持的链接给提示且不发请求；单条帖子详情（长帖全文、作者线程、转帖与引用及原帖不可见的说明、图片 GIF 视频混排、投票卡片文章直播等的摘要）与用户帖子列表（置顶、翻页、可见上限、受保护、空壳与真空区分）；缓存视频（最高码率单文件 MP4）与正文图片（原图、GIF、混排、线程），转帖与引用存转帖者文件夹；订阅关联 X 账号、检查更新（置顶不打断、外层 ID 判新）、自动缓存、全部缓存原创；从 X 关注列表导入；我的 › X 的关注、书签与喜欢；站点小字“X”与五项筛选；X 的保守节奏、主动刹车、遇限流与风控即停，额度、退避与熔断独立；前端变化时只停 X 并说明；远程版确认风险后推送 X Cookie 与同步 X 订阅 | 官方 API 路线、直播与 Spaces、只有分段流的视频、回复与媒体标签、书签文件夹与列表（ACT-024 确认后）、线程续帖、按时间回溯、文章正文、编辑历史、评论 |
