# 决策与事项入口

- [有效决定](confirmed-decisions.md)：用户已明确的方向、来源与边界。
- [架构决策](architecture-decisions.md)：从原设计迁入的 ADR-001～012 及新增治理决定，保留原编号。
- [统一事项总表](open-questions.md)：Q/OSS/ACT/LOOP 的唯一当前状态。

新增长期选择按[决定模板](../templates/decision-record.md)记录，可先在台账写完整小决定；复杂 ADR 才独立文件。不因文件叫 ADR 就要求额外审批，授权范围与职责按[治理](../governance/documentation-policy.md)和当前任务判断。
