# TRACE 产品原则

本文提炼[需求](../requirements.md#product)的长期约束，详细行为与验收以需求正文为准。

| 原则 | 判断方式 | 验收入口 |
| --- | --- | --- |
| 创作者中心、来源可追溯 | 平台账号、发布、版本与文件身份分开，改名不改历史 | AC-01/02 |
| 完整性基于范围和证据 | 下载器 exit 0、页面遍历结束不代表历史全部完整 | AC-03/13/19 |
| 档案可恢复 | 新版失败不损坏旧版，空间不足不暗删历史 | AC-05/12/17 |
| 后台与档案独立 | 关闭界面继续；移除适配器后仍可读档案 | AC-09～11 |
| 质量升级不丢独有信息 | 比较语义、覆盖与规格，不只看“4K”标签 | AC-06/07 |
| 状态真实、用户可控制 | 来源/登录身份分开，未知/网络失败/删除分开，删除范围明确 | AC-08/13/14/21 |
| 通用技术开源优先、MVP 循环 | TRACE 聚焦领域整合；站点下载规则单独验证；按完整流程交付 | [开源规则](../dev-rules/open-source-first.md)、[路线](../delivery/roadmap-and-acceptance.md) |

首批平台、系统顺序与基本范围见[有效决定](../decisions/confirmed-decisions.md)。公共分享、多租户、全网身份推断和通用浏览器抓取不属于本地首版。开发 A/B 协作不意味着产品内置 AI Agent。
