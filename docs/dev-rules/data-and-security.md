# 数据、凭证与恢复约束

触发：下载/录制、数据库、路径、质量回收、备份/导出、凭证、日志与同步。流程正本见[文件提交](../design.md#storage)、[质量](../design.md#quality)、[凭证](../design.md#credentials)、[恢复](../design.md#import-export)、[同步](../design.md#remote-sync)。

| 变更面 | 必须满足 | 验证 |
| --- | --- | --- |
| 文件与数据库 | 临时文件→校验→引用提交可重入；唯一键抗重复 | 中断窗口、重复回调、过期任务，AC-03/05/19 |
| 质量与回收 | 新版验证且切换引用后再考虑回收；保护共享引用、独有覆盖与副本 | 失败/竞态下旧版可读，AC-05～07 |
| 备份/迁移 | 明示媒体范围，隔离目录真实恢复，不兼容版本拒写 | AC-17/18 |
| 凭证/快照 | 令牌、Cookie、签名 URL 不进普通档案；敏感类型隔离 | 哨兵样本检查日志/导出/备份，AC-25 |
| 不可信输入 | 正文不执行脚本，路径由核心定位，外部参数类型化 | 穿越、异常消息、HTML/参数注入，AC-16 |
| 本机控制 | 校验调用方和当前用户边界 | 未授权连接、双实例、重连，AC-10 |
| 删除/同步 | 停订阅、删缓存、删副本、删档案分开，接收方真正保存才确认 | AC-20～22 |

默认用明确隔离的临时 Profile、合成账号/媒体，不触碰真实档案。实际平台测试仅用用户授权账号、内容和请求预算，文档记录脱敏结果。缺配置先做可控源与失败路径，不索要明文密钥写入聊天或 Git。

凭据从本地受保护配置或系统存储读取，不回显。`.gitignore` 不是完整隔离保证。不得通过取消路径、引用或脱敏断言获得绿色结果。

数据语义改变交付可审阅方案与兼容证据；授权内可逆实现和测试连续进行。真实数据删除、覆盖、迁移按具体授权执行，active 文档不代替授权。
