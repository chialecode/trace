# 架构与契约开发约束

触发：模块、后台、数据库调用、插件/API、公共数据或依赖方向变化。先读[不变量](../design.md#invariants)与相关设计章节。

1. domain 不依赖 Tauri、SQLite 驱动或具体网站；UI/API/适配器复用应用服务，不各自重写提交规则。
2. daemon 持有任务与数据库写入权；GUI 关闭不能破坏任务。sidecar 打包支持不等于独立生命周期已实现，须实测重启和双启动竞争。
3. 插件提供规范化事实、能力和版本化扩展，不写核心数据库或决定最终成功/回收。握手、错误、取消、超时与停用收尾共同构成契约。
4. 昵称、下载器文件名、媒体 URL、Cookie 不作稳定身份；替换适配器不改变历史身份和档案可读性。
5. 独立进程不等于安全沙箱。受信任适配器也要检查消息、路径、凭证与取消边界；第三方开放分发另行验证。
6. 格式/API/插件/配置分别版本化；新字段、默认行为与旧数据迁移一起验证，不重写已发布历史迁移。

按当前完整流程创建模块，[目标布局](../design.md#modules)不是空 crate 清单。实际需独立构建、隔离或发布时才拆包；第二个不同来源用来检验抽象，不提前宣称通用 1.0 契约。

通用前端、组件、HTTP/TLS、异步运行、数据库驱动、媒体与搜索按[开源规则](open-source-first.md)整合。TRACE 自有代码聚焦稳定身份、观察版本、归档事务、引用保护、状态解释和业务编排。

公共契约变化交付调用方、持久化影响、兼容/恢复、故障半径和撤回方式，同步[设计](../design.md)、[架构决定](../decisions/architecture-decisions.md)及用例。模块按[规格模板](../templates/module-spec.md)记录必要部分；接口声明不等于可用功能。
