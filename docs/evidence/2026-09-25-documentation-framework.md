用户要求参考既有项目的根文档与 docs 治理方式，为 TRACE 建立可指导 AI Agent 和程序员的文档框架。通过阅读 Cindy 的入口、产品/开发/设计分层及审查规则，借鉴触发式导航与唯一正本；通过阅读 manga 的协作与治理规则，转化后续 A 规划审核、B 实现自检及集中事项流程。未复制参考工程的技术栈、CI、DCO、指定人员审批或发布授权。
